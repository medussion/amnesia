# Brand logo sources

These marks are bundled only to identify the corresponding third-party tools in
Amnesia's provider picker. They are not Amnesia branding and do not imply
endorsement or partnership. All trademarks remain the property of their owners.

- `codex.png`: official Codex icon from the installed OpenAI ChatGPT macOS app.
- `claude-code.png`: official Claude icon from the installed Anthropic Claude macOS app.
- `gemini-cli.png`: official Gemini icon from the installed Google Gemini macOS app.
- `cursor.png`: official Cursor site icon from `https://cursor.com/marketing-static/icon-192x192-light.png`.
- `windsurf.png`: official Devin Desktop site icon from `https://devin.ai/icon.png`;
  Windsurf is represented under its current Devin Desktop branding.
- `copilot.png`: standalone Copilot product icon cropped from GitHub's official
  brand-toolkit asset at `https://brand.github.com/brand-identity/copilot`.

Assets are proportionally resized for the 62-point picker presentation. The
marks themselves are otherwise unmodified.
